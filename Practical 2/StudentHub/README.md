StudentHub - Student Portal Web Application

StudentHub is a lightweight, pure HTML-based student portal designed to manage and display academic information such as notices, course resources, grades, attendance, timetables, and assignments in a simple and intuitive interface.

Project Structure : 
StudentHub/
│
├── index.html         
├── login.html         
├── dashboard.html     
├── assignments.html   
├── attendance.html    
├── contact.html       
├── grades.html       
├── notice.html        
├── resources.html     
├── timetable.html  
└── README.md

Features : 

Authentication: Simple user login screen.

Central Dashboard: Easy navigation hub linking all student services.

View grades and marksheets.

Track attendance records.

View class routines and timetables.

Manage and track assignments.

Stay updated with official announcements.

Contact academic support and administration.

Study Material: Access lecture notes, lab manuals, and useful software links.
